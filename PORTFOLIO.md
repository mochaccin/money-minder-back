# money-minder-back

Simple finance and spending tracker built on React Native, Go std library and MongoDB

## Tags

- React Native
- jwt
- go
- backend
- MongoDB
- finance

## Problem

Needed a small tracker to balance my monthly expenses and visualize how I was spending my money.

## Solution

Simple mobile finance and spending tracker, built with Go since I wanted to try a new programming language, and I might say it was quite a pleasant journey.


## How it works

Simple React Native app that calls to a Go std library REST API, with JWT authentication and MongoDB to serve and store the app information.

## Comments

> Very pleasant experience to try a new programming language and made me fall in love with Go. Also got to skip a university course since I delivered the finished project at the start of the course.
